# Security Policy

## Security & Threat Model

The [Security & Threat Model](docs/content/docs/operations/security.md) is the
canonical description of Flink Agents' trust assumptions, security boundaries,
and deployment responsibilities. Read the document for the version you use.

## Reporting a Vulnerability

Report suspected undisclosed vulnerabilities privately to
[security@apache.org](mailto:security@apache.org), following the
[ASF reporting guidance](https://www.apache.org/security/). Do not disclose them
in public GitHub issues, pull requests, or mailing lists. If you are unsure
whether a report is security-related, use the private channel first.
